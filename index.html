Развёрнутые ответы оценивает преподаватель. Автопроверка доступна только для однозначных числовых задач — не является итоговой оценкой.

Проверка работы

Данные хранятся в облачном проекте Supabase. Администратор системы должен соблюдать требования по защите персональных данных и ограничению доступа. Результаты экзаменов проверяет преподаватель: автоматическая проверка развёрнутых ответов без экспертной оценки не производится.
